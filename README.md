# tlim.app

Site do Tlim, publicado pelo GitHub Pages (branch `main`, pasta raiz). HTML puro, sem build.

- `index.html`, `img/`, `fonts/`: página principal (thread "Criar site institucional do Tlim").
- `privacidade/`, `termos/`, `excluir-conta/`: geradas no app-financas com `npm run site` a partir de `src/features/legal/texts.ts`. Não editar à mão nem mudar os caminhos (o Google Play usa esses links).
- `CNAME` (tlim.app) e `.nojekyll` ficam na raiz.
